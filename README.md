
# WarmPaws – Pet Care in Winter

A cozy winter companion platform designed for pet owners to ensure their furry friends stay warm, safe, and healthy during the cold season. Users can explore local pet care services, winter pet clothing, grooming options, and expert tips — all in one friendly interface

## Live link
https://warmpaws-assignment-09.web.app/  


## Features

- User can book services accoroding to their interest
- Fully responsive in all devices

## Tech Stack

**Client:** React, Router, TailwindCSS

**Npm packages:** Swiper.js, AOS, Hot toast, DaisyUi.


## How to setup project

```bash
  cd my-project
  git clone https://github.com/IGNIT3-xD/Warmpaws.git
  npm i
  npm run dev
```
